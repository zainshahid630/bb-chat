═══════════════════════════════════════════════════════════════════════════════
                              📋 ALL AVAILABLE SCRIPTS
═══════════════════════════════════════════════════════════════════════════════

SETUP & INITIALIZATION:
    npm run android:init          → Create Android project (first time only)

SYNC & UPDATE:
    npm run android:sync          → Build web app + sync to Android

BUILD APK:
    npm run android:build         → Build debug APK
    npm run android:build:release → Build release APK
    npm run apk:debug             → Same as android:build
    npm run apk:release           → Same as android:build:release

UTILITIES:
    npm run apk:find              → Find all APK files
    npm run android:clean         → Clean build cache
    npm run android:install       → Install APK on connected phone
    npm run android:open          → Open in Android Studio

RELEASE APK:
